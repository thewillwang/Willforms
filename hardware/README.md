# hardware/

每个阶段一个子目录：`phase0/`、`phase1/` …

每个子目录里放：

- `BOM.md` —— 物料清单，含备选件、数量、参考价格、采购链接留空由人填写
- `wiring.md` —— 接线表 / 引脚分配（固件里的引脚定义必须与此一致）
- `cad/` —— 外壳与结构件（`.step` 为源文件，`.stl` 为打印件，`.3mf` 可选）
- `pcb/` —— 如果做了转接板 / 自制 PCB，放 KiCad 工程
- `notes.md` —— 组装实测记录：哪里装不上、哪里发热、哪里松

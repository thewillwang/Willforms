# 04 · 阶段 0 详细方案：桌面小黄鸭

## 1. 它长什么样、能做什么

一只约 12 cm 高的 3D 打印黄鸭，坐在一个可拆的底座上，USB-C 供电。

- **听**：双麦克风，你在 1–2 m 内正常说话它能听清；它说话时你插话，它会停下来听（需要 AEC）。
- **说**：云端 LLM 驱动，有固定的性格；流式 TTS，开口快。
- **动**：头部一个舵机做点头 / 抬头 / 低头；翅膀一个舵机做扑腾 / 耸肩。
- **表情**：眼睛两颗 RGB LED（或一圈），用颜色与呼吸节奏表达情绪。
- **感觉**：头顶有电容触摸——摸它会有反应；可选 IMU，被拿起、倾斜时会"惊讶"。
- **离线**：没网时眨眼、偶尔左右看、摸头会"嘎"一声。

## 2. 硬件方案：两条路选一条

### 方案 A（推荐）：ESP32-S3-BOX-3 整机 + 外挂舵机 / LED

- 盒子里已经有：ESP32-S3（16 MB Flash / 8 MB PSRAM）、双麦 + ES7210 ADC（带 AEC 参考通道）、ES8311 DAC + 功放 + 喇叭、2.4 寸触摸屏、USB-C。
- 我们只需外接：2 个舵机、LED、触摸片。通过它的 PMOD / 扩展排针引出 GPIO。
- 优点：音频链路零踩坑，官方有 ESP-SR 的 AEC/VAD/唤醒词例程；屏幕可以直接画一对眼睛，表现力比 LED 强。
- 缺点：形状是方盒子，鸭壳要围着盒子设计（屏幕当"脸"露出来反而可爱）；价格 ¥300–400。

### 方案 B：XIAO ESP32S3 Sense 自己搭

- Seeed XIAO ESP32S3 Sense：拇指大，自带 PDM 麦克风 + OV2640 摄像头 + 8 MB PSRAM，¥90–120。
- 外加：MAX98357A I2S 功放 + 3 W 喇叭、第二颗 I2S 麦克风（INMP441）、舵机、LED、触摸模块。
- 优点：体积小，鸭壳可以做得像鸭子；有摄像头，阶段 1 可直接用；便宜 ¥150–250。
- 缺点：没有硬件 AEC 参考，软件 AEC 要自己对齐时钟，**首版接受"鸭子说话时不能打断"**。

**建议**：先买方案 A，把软件做扎实；方案 B 的板子也买一块（便宜），同时验证自搭音频链路，为阶段 1 的小体积身体做准备。

完整清单见 [`../hardware/phase0/BOM.md`](../hardware/phase0/BOM.md)。

## 3. 引脚与接线（方案 A，初稿，组装时以 `hardware/phase0/wiring.md` 为准）

| 功能 | 器件 | 接口 | 备注 |
|---|---|---|---|
| 头部舵机 | SG90 / MG90S | PWM，GPIO 由扩展口引出 | 外接 5 V，与 BOX-3 共地，电源加 100 µF 电容 |
| 翅膀舵机 | SG90 | PWM | 同上 |
| 眼睛 | WS2812B × 2（或 8 灯环） | 单线 | 5 V，数据线串 330 Ω |
| 头顶触摸 | TTP223 模块或裸铜片 | GPIO（ESP32 自带触摸引脚更好） | 铜片贴壳内壁即可 |
| IMU（可选） | MPU6050 | I2C | 与 BOX-3 内部 I2C 共用总线注意地址 |
| 供电 | USB-C 5 V ≥ 2 A | — | 舵机启动电流大，不要从 BOX-3 的 3.3 V 取电 |

## 4. 软件里程碑

### M0 · 软件鸭（不需要任何硬件，先做）

- `cloud/`：WebSocket 网关 + Claude Agent + 工具定义 + ASR/TTS 适配
- `sim/`：电脑端软件鸭，麦克风进、喇叭出，工具调用打印到终端
- 验收：和软件鸭聊 10 轮，终端能看到 `set_emotion` / `gesture` / `say` 的调用顺序和每段延迟

### M1 · 板子点亮

- 固件：Wi-Fi 配网（BLE 或 SoftAP 网页）、连上网关发 `hello`、心跳、OTA 跑通一次
- 验收：拔网线自动重连；OTA 升级一次

### M2 · 音频闭环

- 固件：I2S 采集 → AEC → VAD → Opus → 上行；下行 Opus → 解码 → 播放
- 验收：真鸭子替换软件鸭，对话跑通；P50 延迟 < 2 s（此时还未优化）

### M3 · 身体与情绪

- 固件：舵机缓动、LED 动画、情绪状态机、触摸 / IMU 事件、离线人格
- 云端：性格 prompt、动作与语音并行调度
- 验收：6 种情绪可辨；"先动再说"生效，主观延迟明显下降

### M4 · 外壳与长跑

- 鸭壳 STEP/STL 定稿、打印、组装
- 验收：阶段 0 全部退出条件（见 [`01-roadmap.md`](01-roadmap.md)）

## 5. 外壳设计要点（给 3D 打印）

- 两件式：上半鸭身（头 + 翅膀舵机座）+ 下半鸭身 / 底座（主板、喇叭、USB 口）。
- 喇叭朝前下方开孔阵列（孔径 2 mm、间距 3 mm），麦克风孔朝上、尽量远离喇叭，孔内不要有尖锐腔体。
- 舵机用卡槽 + 一颗 M2 自攻螺丝固定；舵机臂通过一根 1.5 mm 钢丝 / 打印连杆带动头部，不要让头的重量直接压在舵机轴上。
- 触摸铜片贴在头顶壳内壁，壳厚 ≤ 1.5 mm 时隔壳感应没问题。
- LED 眼睛用半透明白色 PETG 打印眼窝做漫射。
- 壁厚 1.6–2.0 mm，内部留 1 cm 走线空间，底座留散热缝。
- 预留阶段 1 的轮子位：底座尺寸按 N20 电机 + 65 mm 轮子留出空间，避免阶段 1 重做整壳。
